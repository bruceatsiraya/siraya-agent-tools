# 銷售配價與報價版本

## 啟用

先對目標 Worker 綁定的 D1 套用 `0005_sales_pricing.sql`，再發布對應 Worker。遷移將既有報價視為已發出的第 1 版，保留原連結、到期時間與停用狀態。

帳號預設為銷售。由資料庫管理員將指定產品帳號設為產品角色，並檢查更新筆數。以下 SQL 的參數為現有登入名稱。

```sql
UPDATE admin_users SET pricing_role = 'product' WHERE username = ?;
```

產品角色可維護目錄、設定銷售下限、管理模板及審核報價。管理 API 的 ADMIN_TOKEN 也具備產品權限。未配置個別銷售下限的模型使用目錄預設係數作為下限。零價一律需要產品核准。

## 操作

在 `/sales` 選取模型、輸入各模型的實付比例。產品可從「多 vendor 配價與價格模板」把所選模型的配價設為授權下限，或儲存為具名模板。使用相同模板名稱會發行下一版本。停用最新版本會將該模板移出選單。

銷售可在同一區選取多個 vendor，依當前有效價增減或統一指定價格。勾選「覆蓋模型自訂」才會替換已有的模型個別價。套用模板後可繼續微調並發價。

報價低於下限時進入「最近報價」等待產品審核。展開審核明細核對客戶、到期日、模型及價格後，核准該版本。有效期自提交日開始，過期的待審版本須重新修訂。

使用「建立修訂」從已存版本載入模型價格。送出修訂時產生新的版本與獨立連結，舊連結按原期限有效，必要時可手動停用。銷售可管理自己的報價，產品可管理全部報價。
